## English Arguments 60

![Practise a precise expression in context](assets/arguments60-preview.png)

The two expression decks include a meaning, a sentence with a gap, first-letter hints, the full example and a usage note. Make a sentence of your own after checking the answer. The learner ranges are practical guides, not certified CEFR assessments.

The three original packs contain English-only text cards without audio or translations. The Basic English 1000 pack includes translations and audio. The optional LingvoBerry links need internet access. See each pack for its topics, instructions and source link.
